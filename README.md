# SWYNEX Technologies - Data Analytics Internship
##Task 1: Data Cleaning
This project was completed as part of my Data Analytics Internship at SWYNEX Technologies.
The objective of task 1 was to clean and validate a marketing dataset and identify commom data quality issues.
### Dataset
-Dataset: Marketing Dataset
-Number of Records:2241
-Tools Used:Microsoft Excel
### Tasks Performed
#### 1. Missing Values
-Checked for missing and blank values.
-Counted the missing values in each column.
#### 2. Duplicate Values
-Checked the dataset for duplicates values
-Removed duplicate records where record.
#### 3. Incorrect Data Types
-Checked the data types of different columns.
-Identify incorrect datatypes.
#### 4. Inconsistent Values
-Checked categorical columns for inconsistent values.
-Identified the inconsistent values.
### Outcome
The dataset was cleaned and validated by identifying missing values, duplicate records, incorrect data types, and inconsistent values.
This task provided practical experience in data cleaning and data quality analysis.
